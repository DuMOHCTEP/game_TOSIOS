🏮 Продвинутая система освещения TOSIOS

🎯 Что реализовано:
🌑 Динамическое затемнение
Карта становится темной, видны только освещенные области
💡 Свет игрока
Круг света вокруг персонажа с ярким центром
🧱 Тени от стен
Реалистичные тени от препятствий на карте
🦇 Свет монстров
Монстры излучают оранжевое свечение
⚡ Вспышки от пуль
Выстрелы создают яркие вспышки света
🎛️ Настраиваемые параметры
Все аспекты освещения можно настроить
⚙️ Текущие настройки:
Радиус света игрока: 200 пикселей
Уровень темноты: 70% (0.7)
Яркость света: 100% (1.0)
Длина теней: 100 пикселей
Непрозрачность теней: 80% (0.8)
Амбиентный свет: 5% (0.05)
🎮 Как работает система:

1. Загрузка карты: Система читает слой "walls" из Tiled JSON

2. Расчет освещения: Определяет, какие области должны быть освещены

3. Создание теней: Рассчитывает тени от стен на основе геометрии

4. Применение масок: Использует PIXI.js маски для создания эффекта

5. Динамическое обновление: Свет следует за игроком в реальном времени

🎨 Технические детали:

Маски PIXI.js: Используются для создания областей видимости

Рендеринг слоев: Темнота → Тени → Свет → Объекты

Производительность: Расчет теней только для близких стен

Оптимизация: Динамическое обновление только видимых областей
