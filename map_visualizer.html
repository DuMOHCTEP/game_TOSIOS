📋 Формат карт

Карты созданы в редакторе Tiled и экспортированы в JSON формате:

Структура JSON:
{
  "width": 16, // Ширина в тайлах
  "height": 16, // Высота в тайлах
  "tilewidth": 16, // Ширина тайла в пикселях
  "tileheight": 16, // Высота тайла в пикселях
  "tilesets": [...], // Список тайлсетов
  "layers": [ // Слои карты
    {
      "data": [...], // Данные тайлов
      "name": "Tile Layer 1"
    }
  ]
}

🎮 Как использовать карты в игре

В константах:
export const MAPS_NAMES = ['small', 'gigantic'];

В коде игры:
const data = Maps.List[this.mapName]; // Загрузка карты
const tiledMap = new Tiled.Map(data, TILE_SIZE); // Создание объекта карты

Визуализация:
const container = getSpritesLayer(textures, tiledMap.layers);
container.zIndex = ZINDEXES.GROUND;
this.viewport.addChild(container);

🛠️ Создание новых карт

Для создания новых карт:

  1. 📥 Скачайте Tiled Map Editor
  2. 🖼️ Используйте dungeon.png как тайлсет
  3. 🎨 Создайте карту с тайлами 16×16 пикселей
  4. 💾 Экспортируйте в JSON формате
  5. 📁 Сохраните в packages/common/src/maps/
  6. 🔧 Добавьте в index.ts и константы

💡 Совет: Карты автоматически масштабируются и интегрируются с системой освещения!
