# 🚂 Развертывание TOSIOS на Railway

## Быстрое развертывание

### Способ 1: Использование скрипта (рекомендуется)

```bash
# Убедитесь, что у вас установлен Railway CLI
npm install -g @railway/cli
# или
curl -fsSL https://railway.app/install.sh | sh

# Авторизуйтесь
railway login

# Запустите скрипт развертывания
./railway_deploy.sh
```

### Способ 2: Ручное развертывание

1. **Создайте аккаунт на Railway:**
   - Перейдите на [railway.app](https://railway.app)
   - Зарегистрируйтесь или войдите в аккаунт

2. **Установите Railway CLI:**
   ```bash
   npm install -g @railway/cli
   ```

3. **Авторизуйтесь:**
   ```bash
   railway login
   ```

4. **Создайте новый проект:**
   ```bash
   railway init
   # Выберите "Empty Project"
   ```

5. **Свяжите проект с текущей директорией:**
   ```bash
   railway link
   ```

6. **Настройте переменные окружения:**
   ```bash
   railway variables set NODE_ENV=production
   railway variables set PORT=3001
   ```

7. **Разверните приложение:**
   ```bash
   railway up
   ```

8. **Получите URL:**
   ```bash
   railway domain
   ```

## 📋 Конфигурационные файлы

Проект содержит следующие файлы для Railway:

- `railway.json` - основная конфигурация Railway
- `nixpacks.toml` - конфигурация Nixpacks для сборки
- `docker-compose.railway.yml` - Docker Compose для Railway
- `nginx.railway.conf` - nginx конфигурация
- `railway_deploy.sh` - скрипт автоматического развертывания

## 🔧 Технические детали

### Переменные окружения
- `NODE_ENV=production` - режим работы
- `PORT=3001` - порт приложения

### Сборка
- Используется **Nixpacks** для автоматической сборки
- Node.js 18.x + Yarn
- Сборка происходит командой `yarn build`
- Запуск командой `yarn serve`

### Здоровье приложения
- Healthcheck endpoint: `/health`
- Таймаут: 300 секунд
- Максимум перезапусков: 10

## 🚀 После развертывания

1. **Получите URL вашего приложения:**
   ```bash
   railway domain
   ```

2. **Проверьте работу:**
   - Откройте полученный URL в браузере
   - Игра должна загрузиться и быть готова к игре

3. **Мониторинг:**
   ```bash
   railway logs  # Просмотр логов
   railway status  # Статус проекта
   ```

## 🛠️ Устранение неполадок

### Проблема: Сборка не запускается
```bash
# Проверьте логи сборки
railway logs --build

# Убедитесь, что все зависимости указаны в package.json
yarn install
```

### Проблема: Приложение не отвечает
```bash
# Проверьте логи приложения
railway logs

# Проверьте переменные окружения
railway variables
```

### Проблема: Healthcheck fails
```bash
# Проверьте, что приложение слушает правильный порт
railway run "yarn serve"
```
